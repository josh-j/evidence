# Evidence workspace

This repository contains investigation notes, experiment plans, evidence indexes,
and sanitized findings. Raw appliance bundles, database exports, backups, JWTs,
private keys, passwords, and backup-encryption keys must not be committed.

## Active investigations

- [`cisco-ise-3-5-p3-admin-gui-2026-08-30/`](cisco-ise-3-5-p3-admin-gui-2026-08-30/README.md) — Cisco ISE 3.5 Patch 3 recurring Admin GUI and administration-thread-pool degradation after a 3.3 Patch 11 configuration restore.

## Evidence labels

Notes use these provenance labels:

- **Reported** — observed in the affected environment but not independently captured here.
- **Verified locally** — reproduced or inspected on the rooted lab appliance or local experiment data.
- **Inference** — a conclusion supported by evidence but not yet proven causally.
- **Open** — missing evidence or an unanswered question.
